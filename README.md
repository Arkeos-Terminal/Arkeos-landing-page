# Arkeos Terminal

Coming-soon waitlist and docs for [arkeos.xyz](https://arkeos.xyz).

## Before first launch

**Loops waitlist** — in `src/lib/site.ts`, replace `ENTER_LOOPS_ENDPOINT_HERE` with your Loops form URL (`https://app.loops.so/api/newsletter-form/<id>`).

## Stack

TanStack Start, Vite, Tailwind v4, JetBrains Mono.

## Routes

- `/` — waitlist landing
- `/docs` — overview
- `/docs/updates` — launch log
- `/docs/legal` — risk disclaimer, terms, privacy

## Brand

The mark is the official Arkeos A (two parallelograms, traced from the source PNG). Favicon, apple touch icon, and the Open Graph card (`public/og.jpg`) use the same mark.
