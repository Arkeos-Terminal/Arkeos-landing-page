# Arkeos Terminal

Coming-soon waitlist and docs for [arkeos.xyz](https://arkeos.xyz).

## Before first launch

1. **Loops waitlist** — in `src/lib/site.ts`, replace `ENTER_LOOPS_ENDPOINT_HERE` with your Loops form URL (`https://app.loops.so/api/newsletter-form/<id>`).
2. **Governing law** — `site.governingLaw` is set to Delaware. Change it if you incorporate elsewhere.

## Stack

TanStack Start, Vite, Tailwind v4, JetBrains Mono.

## Routes

- `/` — waitlist landing
- `/docs` — overview
- `/docs/updates` — launch log
- `/docs/legal` — risk disclaimer, terms, privacy

## Brand

The mark is a geometric A, authored as SVG (crisp at any size). A PNG original is kept at `public/logo.png`. Favicon, apple touch icon, and the Open Graph card (`public/og.jpg`) are derived from the same mark.
